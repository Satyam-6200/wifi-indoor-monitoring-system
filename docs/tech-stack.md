# Technology stack

## Included

- React 19 + TypeScript.
- Vite 8 for development and production builds.
- Oxlint for static linting.
- Plain CSS for the dependency-free interface.

## Suggested production additions

- Fastify/Express or FastAPI service for collector/API.
- SQLite/PostgreSQL for snapshots and events.
- Deployment-managed secrets for router credentials.
